Sunbird RC is a configurable, domain-neutral foundation for trusted digital registries and credential ecosystems. These applications are reference patterns designed to expand what implementers can imagine—not to limit where Sunbird RC can be used.

SECTORAL IMPLEMENTATIONS

One foundation, configured for different ecosystems

Sunbird RC provides common Registry and Credential building blocks. Each ecosystem configures them around its own authorities, records, trust and service outcomes.

The three reference implementations make this concrete. Identity authorities enable privacy-preserving age proof; farmer and land authorities make rural-credit evidence portable; and education institutions issue qualifications that can be reused for admission and employment. The sectors differ, while the trusted-record-to-credential pattern remains reusable.
